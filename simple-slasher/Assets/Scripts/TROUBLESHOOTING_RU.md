# 🛠️ Решение проблем - Troubleshooting Guide

## 🚨 Частые проблемы и решения

### Проблема 1: Скрипты не компилируются

**Симптомы:** Красные ошибки в консоли Unity, скрипты не работают.

**Решения:**
1. Откройте консоль (`Window` → `General` → `Console`)
2. Найдите первые ошибки в списке
3. Исправьте ошибки в Visual Studio/VSCode
4. Сохраните и вернитесь в Unity
5. Unity автоматически перекомпилирует скрипты

**Частые причины:**
- Отсутствие компонента `using UnityEngine.UI;` в скриптах
- Несовместимость версий Unity
- Опечатки в названиях компонентов

---

### Проблема 2: Игрок не двигается

**Симптомы:** Нажатие WASD не перемещает игрока.

**Решения:**
1. ✅ Проверьте, что на объекте `Player` есть компонент `CharacterController`
2. ✅ Убедитесь, что на сцене есть объект `Ground` с коллайдером
3. ✅ Проверьте позицию `Player` (должна быть выше уровня земли)
4. ✅ Проверьте консоль: должны быть сообщения из InputSystem

**Диагностика:**
```csharp
// Добавьте в Update() PlayerController.cs для проверки:
Debug.Log("Move Input: " + moveInput);
Debug.Log("Is Grounded: " + isGrounded);
Debug.Log("Current Speed: " + currentSpeed);
```

---

### Проблема 3: Враги не спавнятся

**Симптомы:** WaveManager не создаёт врагов.

**Решения:**
1. ✅ Проверьте, что объект `Player` имеет тег `Player`
2. ✅ Убедитесь, что на объекте `Player` есть компонент `PlayerHealth`
3. ✅ Проверьте, что Enemy Prefab назначен в WaveManager
4. ✅ Посмотрите консоль: должно быть "Wave 1 starting with 3 enemies"

**Проверка компонентов:**
```
Player:
- Tag: Player ✓
- PlayerHealth компонент ✓

WaveManager:
- Player: назначен ✓
- Enemy Prefab: назначен ✓
```

---

### Проблема 4: Враги не следуют за игроком

**Симптомы:** Враги спавнятся, но стоят на месте.

**Решения:**
1. ✅ Проверьте, что на врагах есть компонент `Rigidbody`
2. ✅ Убедитесь, что `Use Gravity` включено (галочка)
3. ✅ Проверьте, что вращение заморожено (`Freeze Rotation X, Y, Z`)
4. ✅ Убедитесь, что игрок имеет тег `Player`
5. ✅ Проверьте параметр `Speed` в EnemyController (не 0)

**Настройка Rigidbody:**
- Mass: 1
- Drag: 0
- Angular Drag: 0.05
- Use Gravity: ✓
- Is Kinematic: ✗
- Constraints: Freeze Rotation X, Y, Z

---

### Проблема 5: Атака не работает

**Симптомы:** ЛКМ не наносит урон врагам.

**Решения:**
1. ✅ Проверьте, что на игроке есть компонент `PlayerController`
2. ✅ Убедитесь, что `AttackPoint` назначен и находится в правильной позиции
3. ✅ Проверьте параметр `Attack Range` (должен быть > 0)
4. ✅ Убедитесь, что слой `Enemy` создан и выбран
5. ✅ Проверьте, что враги находятся в слое `Enemy`

**Проверка AttackPoint:**
- Объект `AttackPoint` должен быть дочерним объектом `Player`
- Позиция: (0, 1, 1.5) относительно игрока
- Должен быть назначен в поле `Attack Point` PlayerController

**Проверка слоёв:**
- Создайте слой `Enemy` в `Project Settings` → `Tags and Layers`
- Назначьте этот слой врагам
- Выберите этот слой в поле `Enemy Layer` PlayerController

---

### Проблема 6: Притяжение к врагам не работает

**Симптомы:** ПКМ не перемещает игрока к врагу.

**Решения:**
1. ✅ Проверьте, что камера имеет тег `MainCamera`
2. ✅ Убедитесь, что на игроке есть компонент `PlayerAttract`
3. ✅ Проверьте, что слой `Enemy` выбран в PlayerAttract
4. ✅ Убедитесь, что враг находится в радиусе 20 единиц
5. ✅ Посмотрите консоль: должно быть "Dashing to enemy at position..."

**Настройка камеры:**
- Название: MainCamera
- Тег: MainCamera (важно!)
- Позиция: (0, 5, -10)

---

### Проблема 7: Rage система не работает

**Симптомы:** Ярость не увеличивается или бонусы не применяются.

**Решения:**
1. ✅ Проверьте, что `RageSystem` на том же объекте, что и `PlayerController`
2. ✅ Убедитесь, что на игроке есть компонент `GameIntegrator`
3. ✅ Посмотрите консоль: должно быть "Rage bonuses applied!"
4. ✅ Проверьте GUI (верхний левый угол) - показывает текущую ярость

**Проверка компонентов на игроке:**
```
Player:
- PlayerController ✓
- PlayerAttract ✓
- RageSystem ✓
- PlayerHealth ✓
- GameIntegrator ✓
```

**Диагностика ярости:**
```csharp
// Добавьте для проверки в RageSystem.cs Update():
void Update()
{
    Debug.Log("Current Rage: " + currentRage);
    Debug.Log("Damage Multiplier: " + GetDamageMultiplier());
    Debug.Log("Attack Speed Multiplier: " + GetAttackSpeedMultiplier());
}
```

### Проблема 8: UI не отображается

**Симптомы:** Счётчик волн и количество врагов не видно.

**Решения:**
1. ✅ Проверьте, что объекты `WaveCounterText` и `EnemiesRemainingText` существуют
2. ✅ Убедитесь, что Canvas создан и настроен
3. ✅ Проверьте, что Text назначен в поля WaveManager
4. ✅ Убедитесь, что шрифт назначен

**Быстрое решение:**
WaveManager создаст UI автоматически. Если UI не видно:
- Убедитесь, что `RunOnStart` = true в SceneSetup
- Или создайте UI вручную согласно руководству

---

### Проблема 9: Игра зависает или работает медленно

**Симптомы:** Низкий FPS, лаги, зависания.

**Решения:**
1. ✅ Уменьшите количество врагов (Starting Enemies)
2. ✅ Увеличьте задержку между волнами (Wave Delay)
3. ✅ Уменьшите радиус спавна (Max Spawn Distance)
4. ✅ Отключите тени или используйте более простые материалы
5. ✅ Проверьте консоль на бесконечные циклы или ошибки

**Оптимизация:**
```csharp
// В WaveManager.cs уменьшите нагрузку:
startingEnemies = 2              // Вместо 3
enemiesPerWaveIncrease = 1        // Вместо 2
waveDelay = 7f                   // Вместо 5f
```

---

### Проблема 10: Слои не работают

**Симптомы:** Система слоёв не функционирует, враги не определяются.

**Решения:**
1. ✅ Создайте слой `Enemy` в `Project Settings` → `Tags and Layers`
2. ✅ Назначьте этот слой врагам
3. ✅ Выберите этот слой в параметрах скриптов
4. ✅ Проверьте, что слой правильно выбран в инспекторе

**Создание слоя:**
1. `Edit` → `Project Settings` → `Tags and Layers`
2. Найдите пустой слой (например, User Layer 6)
3. Назовите его `Enemy`
4. Нажмите `Apply`

## 🔍 Общая диагностика

### Шаги для диагностики любой проблемы:

1. **Проверьте консоль:**
   - Откройте `Window` → `General` → `Console`
   - Ищите красные ошибки
   - Исправьте первые ошибки в списке

2. **Проверьте компоненты:**
   - Убедитесь, что все нужные компоненты добавлены
   - Проверьте, что все ссылки назначены в инспекторе
   - Проверьте теги и слои

3. **Используйте Debug.Log:**
   - Добавьте `Debug.Log()` в подозрительные места
   - Проверьте вывод в консоли
   - Определите, где именно проблема

4. **Попробуйте минимальную конфигурацию:**
   - Уберите сложные компоненты
   - Проверьте базовую функциональность
   - Добавляйте компоненты по одному
