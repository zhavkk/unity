## 🎯 Основные механики игры

### 1. Динамическое перемещение и комбо

**Притяжение к врагам:**
- ПКМ на врага → быстрый рывок к нему
- Диапазон: 20 единиц
- Скорость рывка: 15 единиц/сек
- Длительность: 0.3 секунды
- Позволяет строить динамические комбо между врагами

**Движение игрока:**
- WASD - базовое движение
- Left Shift - спринт (быстрее на 60%)
- Space - прыжок
- Плавное ускорение и замедление

### 2. Система ярости

**Накопление ярости:**
- +5 за каждую атаку
- Максимум: 100 единиц

**Бонусы от ярости:**
- Урон: от 1x до 3x (при 100 ярости)
- Скорость атак: от 1x до 2x (при 100 ярости)

**Потеря ярости:**
- -10 в секунду при бездействии (3+ сек)
- -20 при получении урона

**Визуальная индикация:**
- GUI показывает текущую ярость (верхний левый угол)
- Цветовая индикация (по желанию): синий → жёлтый → красный

### 3. Волновая система

**Прогрессия волн:**
- Волна 1: 3 врага
- Волна 2: 5 врагов
- Волна 3: 7 врагов
- И так далее... (+2 врага на каждую волну)

**Паузы между волнами:**
- 5 секунд между волнами
- Автоматическое начало следующей волны

**Конец игры:**
- При смерти игрока
- Показывает количество пережитых волн

## 🚀 Как начать за 5 минут

### Вариант 1: Ручная настройка (рекомендуется)

1. **Откройте проект в Unity**
   - Unity Hub → Add Project → выберите папку проекта

2. **Создайте слой "Enemy"**
   - Edit → Project Settings → Tags and Layers
   - Назовите пустой слой "Enemy"

3. **Следуйте инструкции:**
   - Откройте файл `SCENE_SETUP_MANUAL.md`
   - Выполните все 9 шагов
   - Сохраните сцену
   - Нажмите Play

### Вариант 2: Автоматическая настройка

1. **Создайте пустой объект**
   - Right-click в иерархии → Create Empty
   - Назовите "SceneSetup"

2. **Добавьте скрипт**
   - Add Component → Scene Setup
   - RunOnStart = true

3. **Запустите игру**
   - Нажмите Play
   - Сцена настроится автоматически
   - Следуйте инструкциям в консоли

- Макс. множитель скорости атак: 2x

### Волны
- Начальное количество: 3 врага
- Увеличение: +2 врага на волну
- Пауза между волнами: 5 секунд
- Радиус спавна: 10-20 единиц

## 🎨 Настройка игры

### Изменение сложности

**Проще:**
```csharp
// В EnemyController.cs:
damage = 5;              // Меньше урона от врагов
moveSpeed = 1;           // Медленнее враги

// В PlayerController.cs:
baseDamage = 20;         // Больше урона игрока
baseAttackSpeed = 1.5f;   // Быстрее атаки

// В RageSystem.cs:
ragePerAttack = 10;       // Быстрее накопление ярости
```

**Сложнее:**
```csharp
// В EnemyController.cs:
damage = 20;             // Больше урона от врагов
moveSpeed = 3;           // Быстрее враги

// В PlayerController.cs:
baseDamage = 5;          // Меньше урона игрока
baseAttackSpeed = 0.5f;  // Медленнее атаки
```

### Изменение баланса волн

```csharp
// В WaveManager.cs:
startingEnemies = 5;           // Начать с 5 врагов
enemiesPerWaveIncrease = 3;     // +3 врага на волну
waveDelay = 3f;                // Пауза 3 секунды
minSpawnDistance = 15;           // Спавнить дальше
maxSpawnDistance = 25;           // Спавнить ещё дальше
```

## 🐛 Решение проблем

### Не работает?

1. **Проверьте консоль Unity** - там будут все ошибки
2. **Откройте файл `TROUBLESHOOTING_RU.md`** - детальное руководство
3. **Следуйте чеклисту** в SCENE_SETUP_MANUAL.md
4. **Попробуйте создать сцену заново** с начала

### Частые проблемы:

| Проблема | Решение |
|----------|----------|
| Не двигается | Проверьте CharacterController и Ground |
| Враги не спавнятся | Проверьте тег Player и PlayerHealth |
| Атака не работает | Проверьте AttackPoint и слой Enemy |
| Притяжение не работает | Проверьте тег MainCamera |
| Rage не работает | Проверьте GameIntegrator на игроке |
