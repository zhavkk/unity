# 🎮 Руководство по настройке сцены

## ⚡ Быстрая настройка (5 минут)

### Шаг 1: Откройте проект в Unity
1. Откройте Unity Hub
2. Нажмите "Add project" и выберите папку проекта
3. Откройте проект
4. Откройте сцену `Assets/Scenes/SampleScene.unity`

### Шаг 2: Создайте слой "Enemy"
1. В верхнем меню: `Edit` → `Project Settings` → `Tags and Layers`
2. В разделе "Layers" найдите пустой слой (например, Layer 6)
3. Назовите его `Enemy`
4. Нажмите `Apply`

### Шаг 3: Создайте игрока

**1. Создайте объект игрока:**
- В иерархии: `Right-click` → `3D Object` → `Capsule`
- Назовите его `Player`
- Установите позицию: `(0, 1, 0)`
- Установите масштаб: `(1, 2, 1)`
- Тег: `Player` (в инспекторе вверху)

**2. Настройте Character Controller:**
- Нажмите `Add Component` → `Character Controller`
- Настройте параметры:
  - Height: `2`
  - Radius: `0.5`
  - Slope Limit: `45`
  - Step Offset: `0.3`
  - Skin Width: `0.08`

**3. Создайте точку атаки:**
- Правый клик на `Player` → `Create Empty`
- Назовите `AttackPoint`
- Установите позицию: `(0, 1, 1.5)`

**4. Добавьте скрипты:**
- Нажмите `Add Component` → `Player Controller`
  - Attack Point: перетащите `AttackPoint`
  - Attack Range: `2`
  - Enemy Layer: выберите `Enemy`
- Нажмите `Add Component` → `Player Attract`
  - Enemy Layer: выберите `Enemy`
- Нажмите `Add Component` → `Rage System`
- Нажмите `Add Component` → `Player Health`
- Нажмите `Add Component` → `Game Integrator`

### Шаг 4: Создайте префаб врага

**1. Создайте врага:**
- В иерархии: `Right-click` → `3D Object` → `Capsule`
- Назовите `Enemy`
- Установите масштаб: `(0.8, 0.8, 0.8)`
- Тег: `Enemy`
- Слой: `Enemy`

**2. Настройте Collider:**
- На объекте `Enemy` уже есть Capsule Collider
- Настройте параметры:
  - Height: `1.5`
  - Radius: `0.4`
  - Center: `(0, 0.75, 0)`

**3. Добавьте Rigidbody:**
- Нажмите `Add Component` → `Rigidbody`
- Настройте параметры:
  - Mass: `1`
  - Drag: `0`
  - Angular Drag: `0.05`
  - Use Gravity: `✓`
  - Is Kinematic: `✗`
  - Constraints: выберите `Freeze Rotation X, Y, Z`

**4. Добавьте скрипты:**
- Нажмите `Add Component` → `Enemy Controller`
  - Health: `30`
  - Damage: `10`
  - Speed: `2`
- Нажмите `Add Component` → `Enemy Health`
  - Max Health: `30`

**5. Сохраните как префаб:**
- Перетащите `Enemy` из иерархии в папку `Assets/Scripts/`
- Или создайте папку `Assets/Prefabs/` и перетащите туда
- Удалите `Enemy` из иерархии (оставьте только префаб)

### Шаг 5: Создайте Wave Manager

**1. Создайте менеджер волн:**
- В иерархии: `Right-click` → `Create Empty`
- Назовите `WaveManager`

**2. Добавьте скрипт:**
- Нажмите `Add Component` → `Wave Manager`
- Настройте параметры:
  - Player: перетащите `Player`
  - Enemy Prefab: перетащите созданный префаб врага
  - Starting Enemies: `3`
  - Enemies Per Wave Increase: `2`
  - Wave Delay: `5`
  - Min Spawn Distance: `10`
  - Max Spawn Distance: `20`

### Шаг 6: Создайте окружение

**1. Создайте землю:**
- В иерархии: `Right-click` → `3D Object` → `Plane`
- Назовите `Ground`
- Установите масштаб: `(20, 1, 20)`
- Позиция: `(0, 0, 0)`

**2. Настройте материал (по желанию):**
- Создайте материал: `Right-click` в Project → `Create` → `Material`
- Назовите `GroundMaterial`
- Цвет: серый `(0.3, 0.3, 0.3)`
- Перетащите на объект `Ground`

### Шаг 7: Настройте камеру

**1. Настройте Main Camera:**
- Выберите `Main Camera` в иерархии
- Убедитесь, что тег: `MainCamera`
- Позиция: `(0, 5, -10)`
- Вращение: `(15, 0, 0)`

### Шаг 8: Создайте освещение

**1. Создайте направленный свет:**
- В иерархии: `Right-click` → `Light` → `Directional Light`
- Позиция: `(10, 10, 0)`
- Вращение: `(50, -30, 0)`
- Интенсивность: `1`
- Shadows: `Soft Shadows`

### Шаг 9: Сохраните сцену

1. `File` → `Save` (или `Ctrl+S`)
2. Запустите игру (`Play` кнопка вверху)

## 🎯 Проверка после настройки

Перед запуском убедитесь:

✅ **Проверка игрока:**
- [ ] Объект `Player` существует в иерархии
- [ ] Тег: `Player`
- [ ] Имеет CharacterController
- [ ] Имеет все скрипты (PlayerController, PlayerAttract, RageSystem, PlayerHealth, GameIntegrator)
- [ ] Имеет дочерний объект `AttackPoint` в позиции (0, 1, 1.5)

✅ **Проверка врага:**
- [ ] Префаб `Enemy` существует в Project
- [ ] Тег: `Enemy`
- [ ] Слой: `Enemy`
- [ ] Имеет CapsuleCollider
- [ ] Имеет Rigidbody с замороженным вращением
- [ ] Имеет EnemyController и EnemyHealth

✅ **Проверка WaveManager:**
- [ ] Объект `WaveManager` существует
- [ ] Player назначен
- [ ] Enemy Prefab назначен

✅ **Проверка окружения:**
- [ ] `Ground` существует с масштабом (20, 1, 20)
- [ ] `Main Camera` имеет тег `MainCamera`
- [ ] `DirectionalLight` существует

✅ **Проверка слоев:**
- [ ] Слой `Enemy` создан в Project Settings

## 🎮 Управление в игре

После запуска:

- **WASD** - движение
- **Left Shift** - спринт
- **Space** - прыжок
- **ЛКМ** - атака
- **ПКМ** - притяжение к врагу

## 🐛 Решение проблем

### Проблема: Игрок не движется
- Проверьте CharacterController на игроке
- Убедитесь, что есть земля с коллайдером
- Проверьте консоль Unity на ошибки

### Проблема: Враги не следуют за игроком
- Проверьте, что игрок имеет тег `Player`
- Убедитесь, что враги имеют EnemyController
- Проверьте Rigidbody на врагах (gravity = on)

### Проблема: Притяжение не работает
- Проверьте тег `MainCamera` на камере
- Убедитесь, что слой `Enemy` настроен правильно
- Проверьте, что PlayerAttract добавлен к игроку

### Проблема: Rage система не работает
- Убедитесь, что RageSystem на том же объекте, что и PlayerController
- Проверьте консоль на сообщения "Rage bonuses applied!"

### Проблема: WaveManager не спавнит врагов
- Убедитесь, что Player назначен в WaveManager
- Проверьте, что префаб врага назначен
- Убедитесь, что игрок имеет PlayerHealth компонент

- Создайте материал → выберите цвет: RGB(0.3, 0.3, 0.3)
- Перетащите на объект `Ground`
