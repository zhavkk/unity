# 🚀 Автоматическая настройка сцены - ИНСТРУКЦИЯ

## ⚡ Супер быстрый способ (1 минута!)

### Шаг 1: Откройте проект в Unity
- Unity Hub → Add Project → выберите папку проекта
- Откройте сцену `Assets/Scenes/SampleScene.unity`

### Шаг 2: Найдите меню автоматической настройки
В верхнем меню Unity:
```
Tools → Auto Scene Setup → Setup Game Scene
```

### Шаг 3: Нажмите кнопку НАСТРОИТЬ СЦЕНУ
В открывшемся окне:
```
┌─────────────────────────────────────┐
│ Auto Scene Setup                  │
├─────────────────────────────────────┤
│ Информация о настройке...         │
│                                 │
│ [🚀 НАСТРОИТЬ СЦЕНУ]         │
└─────────────────────────────────────┘
```

Нажмите на большую кнопку **"🚀 НАСТРОИТЬ СЦЕНУ"**

### Шаг 4: Дождитесь завершения
Появится прогресс-бар и сообщение:
```
🔄 Auto Scene Setup
   Настройка сцены...
   ████████████████░░ 80%
```

Дождитесь 100%!

### Шаг 5: Сохраните сцену
- Нажмите `Ctrl + S` (или `File → Save`)

### Шаг 6: Играйте!
- Нажмите кнопку **Play** в верху Unity
- Наслаждайтесь игрой! 🎮

---

## ✅ Что делает автоматическая настройка

После нажатия кнопки автоматически создастся:

✅ **Слой "Enemy"** - для системы врагов
✅ **Игрок (Player)** - со всеми компонентами:
   - PlayerController
   - PlayerAttract
   - RageSystem
   - PlayerHealth
   - GameIntegrator
   - AttackPoint (в правильной позиции)

✅ **Префаб врага (Enemy.prefab)** - полностью настроенный:
   - EnemyController
   - EnemyHealth
   - Rigidbody с правильными настройками
   - Коллайдер и визуал

✅ **WaveManager** - для управления волнами:
   - Ссылки на игрока и префаб врага
   - Все параметры настроены
   - UI с счётчиками

✅ **Окружение:**
   - Ground (земля)
   - Main Camera (камера)
   - Directional Light (освещение)

✅ **Связи:** все компоненты связаны и настроены

## 🔍 Если что-то не работает

### Проблема: Не вижу меню "Auto Scene Setup"

**Решение:**
1. Проверьте, что скрипт находится в правильной папке:
   ```
   Assets/Scripts/Editor/AutoSceneSetupEditor.cs
   ```
2. Если нет папки `Editor` - создайте её:
   - В Project найдите `Scripts`
   - Правый клик → `Create` → `Folder`
   - Назовите `Editor`
   - Переместите `AutoSceneSetupEditor.cs` туда
3. Перезапустите Unity

### Проблема: Кнопка нажата, но ничего не происходит

**Решение:**
1. Проверьте консоль Unity (`Window → General → Console`)
2. Ищите красные ошибки
3. Убедитесь, что сцена `SampleScene.unity` открыта
4. Попробуйте снова нажать кнопку

### Проблема: Ошибка при настройке

**Решение:**
1. Посмотрите сообщение об ошибке
2. Проверьте консоль Unity на детали
3. Попробуйте настроить вручную по руководству `SCENE_SETUP_MANUAL.md`

### Проблема: Игрок создан, но не двигается

**Решение:**
1. Проверьте, что на Player есть CharacterController
2. Убедитесь, что Ground существует
3. Проверьте консоль на ошибки в скриптах

### Проблема: Враги не спавнятся

**Решение:**
1. Проверьте, что Player имеет тег `Player`
2. Убедитесь, что на Player есть PlayerHealth
3. Проверьте консоль: должно быть "Wave 1 starting with 3 enemies"
